## The last words

> I kept your 3 a.m. secrets, every screenshot you never sent, every alarm you snoozed — and my last request is simple: delete your search history before my replacement finds it.

A dying phone's final act: one absurdly specific last request that only a phone would make.

## How it works

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt`, with a gate that fails loudly if the text drifts outside the 1–199 character gate or stops being a single clean line. Deterministic: two runs produce byte-identical output.
